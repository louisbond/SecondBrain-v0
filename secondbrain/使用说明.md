# SecondBrain 使用说明

面向**直接使用程序的人**。想改代码、跑测试、打包，请看 [README](../README.md)。

## 这是什么

一个跑在你自己电脑上的个人知识库工具：把链接、视频、随手记的内容采集成原文，
由 AI 起草摘要，你逐条核准分区和标签后写成 Markdown 笔记。
**Markdown 文件是唯一真相源**，数据库只是可随时重建的索引。

## 安装与启动

- 系统：Windows 10 / 11（界面依赖系统自带的 Edge WebView2 运行时）
- 把整个程序目录解压到任意位置，双击 `SecondBrain.exe` 即可
- **不需要配置、不需要账号、不需要联网**，第一次打开就能用
- 程序未做代码签名，Windows SmartScreen 可能拦截：点「更多信息」→「仍要运行」

服务只监听 `127.0.0.1:7688`，默认不允许局域网访问；端口被占用时会自动顺延并在日志里提示。

## 我的数据在哪

首次运行会在你的用户目录创建 `~/.secondbrain/`（Windows 上是 `C:\Users\<用户名>\.secondbrain\`）：

| 路径 | 内容 |
|---|---|
| `config.toml` | 配置（由程序自动生成，可手改） |
| `secrets.json` | API 密钥（与配置分开存放） |
| `data/secondbrain.db` | 索引数据库 |
| `data/logs/app.log` | 运行日志（自动轮转） |
| `vault/` | 默认笔记库（未指定自己的库时使用） |

数据放在用户目录而不是程序目录，所以把程序装到 `C:\Program Files` 这类只读位置也能正常使用。

**便携模式**：如果 exe 同级已经存在 `config/` 和 `data/` 目录，程序会**优先用它们**，
不再读用户目录。判断方法是看「设置 → 常规设置」里显示的数据库路径指向哪里。
两种方式不要混用 —— 混用会出现"改了设置不生效"，因为改动写进了另一套配置。

## 换成自己的 Obsidian 库

**设置 → 常规设置 → Vault 目录** → 填入你的库根目录绝对路径 → 点「切换」。
之后建议点一次「扫描存量 vault」或「重建索引」，让已有 md 进入索引。
不换也行，程序会用上面那个默认库。

## AI 功能（可选）

**设置 → AI 与密钥**：

- **不填也能用**：采集原文、手动核准、写笔记、全文搜索、标签与分区管理都不依赖 AI
- 填入 OpenAI 兼容端点（火山方舟 / DeepSeek 等）的 API Key 后，才能用 AI 摘要、
  模板化解析、自动建议标签分区
- 密钥只写进 `secrets.json`，不会写进 `config.toml`，也不会随日志输出
- 「AI Provider」页能看到每条链路是否可用；不可用时程序会提示，不会静默失败

模型在**各自所在页面的控件**里选：采集区是提取链，加工区是创作链。
两条链可以一条本地、一条 API，互不影响。

## 语音转写与音频归档

B 站等视频没有字幕时，可用 faster-whisper 转写音频。模型在首次使用时下载；
没有网络或缺少依赖时，设置页「语音转写」会显示「未安装 / 缺失」并给出提示，
其余功能照常可用。

**无论来源是视频链接还是本地文件，抽出的音频都会统一归档成 MP3**
（128kbps 单声道，10 分钟约 9.6MB，是原视频的 5%）。文本是降维产物 ——
语气、停顿、重音、情绪全丢了，只有音频还能听出来。归档之后可以：

- 在「任务状态」页点「听音频」，按时间码跳转，边听边核对文本
- 导出 SRT / TXT，给任何播放器或剪辑软件用
- 换模型重转写，不用求人重发视频（链接失效也不影响）

原视频默认在处理完成后删除（`[media] keep_video = true` 可以保留）。
归档目录是 `<数据目录>/media/audio/`，与缓存分开 —— 清缓存不会误删。

## 画面文字识别（OCR，兜底）

抖音上很多视频是纯字幕、BGM 盖过人声、或者方言太重，转写拿不到东西。
这时程序会自动改读**画面上的字**（本地 OCR，图片不外发）。

默认只在「语音转写没结果」时触发 —— 有口播的视频 OCR 拿到的是同样的话，
纯属浪费十几秒。B 站跳过（官方字幕质量更好）。可以在 `config.toml` 里调：

```toml
[ocr]
auto_trigger = "asr_empty"   # always = 每条都跑；off = 关掉
llm_fix = true               # 有本地 ollama 时自动修错字
```

识别结果会作为独立段落 `## 画面文字（OCR）` 追加，不覆盖口播正文 ——
OCR 有水印、UI、图表数字，混在一起会让 AI 摘要跑偏。

## 抓不到视频链接怎么办

抖音/快手在未登录时不返回视频直链，小红书图文也没有音轨。
这类来源在采集框里抓不到东西时，**直接在 App 里把视频保存到电脑，
用采集区的「导入视频」按钮上传**（支持多选）。程序按文件内容去重，
同一个视频传两次不会重复入库，音频照样归档、照样能听能导出。

单个文件上限 **500MB**（手机拍的 20 分钟 1080p 约 400MB）。要改就在
`config.toml` 里调 `[media] max_file_mb`，本地上传和视频直链下载共用这一个数。

## 界面说明（各区域在做什么）

程序界面尽量只放必要信息，详细解释集中在这里。

### 采集区

- **粘贴**分享文案或链接 → 点「解析链接」。解析即入库，条目直接进采集队列
- 每次粘贴时，程序会自动在**每个链接后面补两个空格** —— 链接边界更清晰，
  不会把后面的中文吃进链接里
- **导入视频/音频**：抖音/快手匿名抓不到直链时，先在 App 里把视频存到电脑，
  再在这里上传（支持多选，按内容去重）
- **采集音频**：勾上后即使文本够长也强制下载音频转写，口播台词和 MP3 一起归档
- 队列三态：**待采集**（含失败条目）/ **采集中** / **已采集**
- 已采集的条目可以「素材入库」收进未加工队列，也可以重新采集或删除

### 加工区（核准区）

流程：原文 → AI 总结 → 加手稿 → 标签 → 分区 → 入库。

- **原文**：加工区顶部直接显示抓到的原文（带行号，可收起）。旁边有字数徽标：
  - 绿色 = 字数正常（≥200 字）
  - 黄色 = 原文太短，多半只抓到标题/简介，没有真正的正文
  - 红色 = 根本没有原文

  队列 chip 上同样会标「·薄」，悬停能看到实际字数 —— 不用逐条点开才知道素材是空的。

  **素材短的时候，AI 总结的目标字数会自动下调**（不超过原文字数，最低 100 字）。
  比如素材只有 73 字却要 800 字摘要，AI 根本写不出来 ——
  以前会反复重试 3 次、耗 5 分多钟最后还是失败。

  目标下调后，接受区间也会放宽（达到目标的 60% 即可），
  且最多只重试一轮 —— 实测 AI 的输出长度由内容决定，提示词要求多少它也不一定给多少。

- **AI 总结**：选模板和字数档位后生成；低于目标字数会自动重新生成（最多 3 次）
- **个人手稿**：写你自己的理解，是图谱里的主节点
- **标签 / 分区**：标签可从词表选也可手打；新分区勾选后自动创建
- **总结入库**：保存 AI 摘要 + 手稿 + 标签 + 分区
- 采集区的「素材入库」只存原文，和这里的「总结入库」不是一回事

### 采集失败的情况

| 情况 | 结果 |
|---|---|
| 抓不到正文（只有标题/简介） | 判**采集失败**，退回「待采集」 |
| 本地模型读不到字幕或音频（ASR 失败 / 转写为空），且原文也是空的 | 判**采集失败**，退回「待采集」，并写明原因 |
| OCR 兜底也失败 | 同样退回「待采集」 |
| 原文本身有实质内容，只是转写失败 | 保留在「已采集」并标记 `asr_failed`（素材仍可用） |

失败的条目可以重新采集或删除，不会静默变成"成功但正文是空的"。

抖音/快手这类平台，网页接口只给得到**用户发的那句话**（几十字），
不含视频里的口播内容。程序会自动取到视频直链并下载转写；
拿不到直链时会明确判失败，提示你用「导入视频/音频」上传本地文件。
登录态 Cookie 能让平台返回更多内容（标题、文案、播放地址），但**字幕不在网页里**，
只能靠本机转写得到。

### 原创区

- 从**空模板**生成骨架（知识提炼 / 知识聚合 / 日记 / 周回顾 …），填详情即可归档
- 保存前必须填标题、正文、标签、分区

### 首页

- 左侧**知识图谱**：手稿是主节点，拖拽旋转、滚轮缩放、点击打开
- 右侧**文件树**：可拖文件到目录做物理移动，图谱跟着变
- 搜索展开后可按分区 / 标签 / 范围筛选，并管理分区与标签

### 两条 AI 链路

程序分两条独立的模型链，各自在所在页面的控件里选「本地 / API」：

- **提取链**（采集区）：负责抓取和转写
- **创作链**（加工区）：负责 AI 摘要和标签建议

两条链互不影响，切换即时生效、选择会被记住。

### 主题与界面密度

设置 → 个性化。深色 / 浅色 / 跟随系统，紧凑 / 舒适两档密度。
两者都是**纯前端偏好**，不写进 `config.toml`，换机器不会同步。

### 提示词模板

设置 → 提示词模板，分四区：

| 分区 | 用途 |
|---|---|
| **采集** | 采集阶段清洗网页/视频原文时的规则。当前采集走解析接口 + ASR，不调 LLM，此模板用于自定义采集清洗流程 |
| **解析** | AI 摘要用的模板。逐个模板编辑，可指定每个模板的标题和目标字数 |
| **个人创作** | 原创区的空模板。Markdown 骨架，支持 `{{date}}` / `{{time}}` / `{{title}}` 占位符（应用时替换成真实值）。**别写 YAML 头** —— 系统会自动生成，写两遍 Obsidian 打不开 |
| **面向接口（AI 提示词）** | 链接/音视频生成摘要与标签时，直接发给模型的原始指令。换 API 链后风格不对、或想让摘要更贴合习惯，改这里 |

可用占位符：`{content}` `{content_type}` `{style_hint}` `{partitions_list}` `{tags_list}`

### 局域网访问（手机访问电脑）

设置 → 维护与系统 → 网络。开启 LAN 后：

- 手机用 `192.168.x.x` / `10.x.x.x` 的地址，**不要用 127.0.0.1**（它只指向手机自己）
- 「复制带 token 的手机链接」→ 在手机浏览器打开一次，token 会自动记住
- 链接别发给不信任的人

### 第三方解析接口（可选）

设置 → 常规设置 → 第三方解析。地址模板里：

- `{url}` 占位表示目标链接（自动 URL 编码）
- `{key}` 占位会被「密钥」栏的值替换（存在密钥库，不写进配置文件）

预设只是填空，地址仍可手改。测解析不会写库。

### API 密钥

设置 → API 密钥。支持火山方舟等 OpenAI 兼容服务，密钥只写入
`config/secrets.json`，不落 `config.toml`。

### 登录态

程序内部会用本机已存的登录态去抓取平台页面（存在 `config/secrets.json`，只在本机）。
设置页不再提供登录态配置入口。

实测各平台登录态的作用（同一链接对照）：

| 平台 | 不带登录态 | 带登录态 | 说明 |
|---|---|---|---|
| **抖音** | 抓不到（0 字） | 标题 + 文案 + 视频直链 | **决定性**。没它连一句话都拿不到 |
| **B站** | 只有 35 字（标题+简介） | 540 字 | **很有用**，主要为了拿 AI 字幕 / UP 主字幕 |
| 快手 | 79 字 | 79 字（一样） | 没用，快手页面数据本来就公开 |

**但要清楚登录态解决不了什么**：
它决定的是"平台愿不愿意把数据给你"，**永远解决不了"视频里的口播台词"** ——
抖音/快手的台词在视频文件里，不在网页里，只能下载视频 + 本机 faster-whisper 转写得到。

想要完整正文，需要两样齐全：
1. **登录态** —— 让平台愿意返回页面数据（否则连播放地址都拿不到）
2. **视频直链 + 本机转写** —— 把视频里的口播变成文字

想确认某个平台当前能不能用，去设置页「平台适配器能力」用一条真实链接点「实测」，
结果会直接告诉你：拿到几条视频直链、正文是否完整。

### 索引与数据库

索引 = 搜索 / 图谱 / 相似笔记用的本地数据库表，**不是你的笔记本身**。
md 文件才是数据本体；索引丢了、乱了都能从 md 重新生成。

数据库文件（SQLite）里存着索引、采集/加工队列、任务进度和统计，
但**不含**你的笔记正文 —— 正文是 vault 里的 md 文件。
这个文件损坏只会丢流程状态，md 笔记不受影响（重建索引即可恢复）。

「程序服务」指的是 SecondBrain 自己的后台进程（本机回环地址上的那个 Web 服务），
不是数据库。关掉它等于退出程序：界面会断连，重新双击 exe 即可恢复，
不会删除任何笔记、原文或数据库记录。

### 开机自启与电源

使用 Windows 任务计划程序（登录时启动），需要管理员权限。

### 网络诊断

设置 → 维护与系统 → 网络诊断，分「内网通 / 外网不通」两组检查项。
手机连不上时，看「局域网入口」这一条。

笔记本休眠或关机 = 服务下线。批量任务运行时请接通电源并把电源策略设为「永不睡眠」。

### 采集失败时会发生什么

- 抓不到正文（只有标题/简介）→ 判定**采集失败**，退回「待采集」
- 本地模型读不到字幕或音频（ASR 失败 / 转写结果为空），且原文也是空的
  → 同样判定**采集失败**，退回「待采集」，并在失败原因里写明
- OCR 兜底也失败 → 同样退回「待采集」
- 原文本身有实质内容时，转写失败不影响该素材可用，会保留在「已采集」并标记
  `asr_failed`

失败的条目可以重新采集或删除，不会静默变成"成功但正文是空的"。

## 备份、迁移与卸载

- **备份**：直接复制 `~/.secondbrain/` 和你的 vault 目录即可
- **数据库丢了也不怕**：md 是唯一真相源，用「设置 → 常规设置 → 重建索引」即可恢复
- **迁移**：复制上述目录到新电脑，再在设置里把 vault 路径改成新位置
- **卸载**：删除程序目录不会动你的数据；想彻底清理再删 `~/.secondbrain/`

## 隐私说明

- 笔记、原文、密钥**只保存在本机**，程序不向作者或任何服务器上传这些内容
- 只有你主动做的事才会产生对外请求：抓取网页/视频、调用你配置的 AI 端点、下载 ASR 模型
- 局域网访问默认关闭；开启时强制 token 校验
- 崩溃日志只写本机文件，不自动外发

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 | 看 `~/.secondbrain/data/logs/app.log`；也可用 `POST /api/settings/shutdown` 关掉残留服务 |
| 界面空白 | 确认程序目录下 `_internal/frontend/dist/` 完整 |
| 抖音 / 小红书抓不到 | 平台反爬，设置页「平台适配器能力」会显示支持度；可手动粘贴原文或速记 |
| 摘要质量差 | 换更大的 ASR 模型，或在加工区选模板、调字数档位重新生成 |
| 端口冲突 | 程序自动顺延，日志里会写实际端口 |
